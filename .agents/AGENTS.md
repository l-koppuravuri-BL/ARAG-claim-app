# Workspace Customization Rules & Constraints

## Do Not Run Local Web/API Servers
- **Constraint**: The local environment does not have Python, Node.js, or web server-related modules installed.
- **Rule**: Do not attempt to run, verify, or serve the website or backend API locally (e.g. using `python backend/index.py`, `node backend/index.js`, or static web servers).
- **Alternative**: Perform verification by reviewing the code implementation, syntax correctness, and visual alignment statically.
